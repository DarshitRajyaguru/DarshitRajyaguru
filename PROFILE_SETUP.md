# Profile README setup

This kit is designed for your existing GitHub profile repository.

## Publish

1. Go to your **DarshitRajyaguru** GitHub account.
2. Open the public repository named **DarshitRajyaguru** (exactly the same as your username).
3. Replace the root `README.md` with the `README.md` from this kit.
4. Upload the `.github/assets/profile-hero.svg` file, preserving the folder structure.
5. Commit both files to the default branch and refresh `https://github.com/DarshitRajyaguru`.

`preview.html` is provided only as a local visual mockup; it is not needed in the GitHub repository. `profile-preview.png` is a screenshot, also not required for deployment.

## Customization

- To change your headline or name styling, edit `.github/assets/profile-hero.svg`.
- Replace email, portfolio and social URLs in `README.md` if they change.
- Add public client case studies only where permission is granted; link results/metrics only when verifiable.
- Keep the official WordPress themes/plugin links current.
- The optional GitHub stat cards load from a third-party service and may sometimes fail; the README is designed to work without them.

## Design notes

- GitHub profile READMEs do **not** support arbitrary custom CSS or JavaScript. The hero is a self-contained SVG and the rest uses supported Markdown/HTML.
- The layout favors accessible links, less visual clutter and credible public proof over exaggerated performance promises.
